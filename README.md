# Sistema de Cadastro

Projeto acadêmico desenvolvido em React para a disciplina de Front-End (IPOG Goiânia). Permite cadastrar e consultar contatos.

## Tecnologias

- React
- Vite
- React Router

## Como executar

```bash
cd frontend
npm install
npm run dev
```

Depois, inicie o backend (ajuste o comando conforme o seu):
```bash
cd backend
npm install
npm run start
```

Acesse: `http://localhost:5173`
